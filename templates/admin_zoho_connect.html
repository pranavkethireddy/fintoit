🛠️ One-Time Setup Guide
Complete steps 1–3 once in the Zoho console, then click Connect to Zoho below. After that, everything is automatic forever.
1
Create a Zoho OAuth Client
Go to api-console.zoho.com → click Add Client → choose Server-based Applications. Give it any name (e.g. "Fintoit Sync").
2
Set the Redirect URI
In the client settings, add this exact redirect URI:
https://www.fintoit.com/admin/zoho/callback
3
Add these environment variables to Render
Copy the Client ID and Client Secret from the Zoho console into your Render dashboard (Environment → Add Environment Variable):
VariableWhere to find it
ZOHO_CLIENT_ID Zoho API Console → your client → Client ID
ZOHO_CLIENT_SECRET Zoho API Console → your client → Client Secret
ZOHO_REDIRECT_URI https://www.fintoit.com/admin/zoho/callback
4
Authorise Fintoit to access your Zoho CRM
Click the button below. You'll be taken to Zoho's login page. After you approve, you'll be redirected back here and the connection will be active permanently (auto-refresh handles token expiry).
